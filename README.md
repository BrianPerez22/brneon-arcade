## 🎮 Elige tu juego

| Juego | ¿Qué te espera? | Para jugar |
|---|---|---|
| 🐾 **Capy Run** | Salta corales y esquiva medusas en una carrera submarina. Reta a un amigo online. | Solo o 1 vs. 1 online |
| 🎱 **Neon 2048 Pool** | Apunta, rebota y parte las fichas para alcanzar el 2048. | Un jugador |
| 🏒 **Air Hockey** | Enfréntate a la CPU, juega en la misma pantalla o crea un duelo online. | 1 o 2 jugadores · Online |
| 🎲 **Suerte 2048** | Voltea fichas sorpresa y suma más puntos que tu rival. | CPU · Online 1 vs. 1 |
| 🧩 **2048 Clásico** | Desliza y combina números hasta llegar a 2048. | Un jugador |
| 💦 **Ruleta Colombiana** | Pasa el tambor y descubre quién recibe el chorro de agua. | Fiesta de 2 a 8 jugadores |

> **Tu próxima partida está a un clic:** [▶ Abrir brneon Arcade](https://brianperez22.github.io/brneon-arcade/)

## ✨ Dentro del arcade

- Estética arcade de neón, con música y efectos de sonido opcionales.
- Skins y colores para personalizar bolas, paletas, discos y capibaras.
- Salas online para jugar con amigos en los modos compatibles.
- Controles táctiles para celular y teclado o mouse en computadora.
- Récords e historial guardados en el dispositivo.

## 🕹️ Controles rápidos

| Juego | Celular | Computadora |
|---|---|---|
| Neon 2048 Pool | Arrastra para apuntar y suelta para lanzar. | Arrastra con el mouse y suelta. |
| Air Hockey | Arrastra tu paleta; en pantalla compartida, cada jugador usa su mitad. | Mouse · J1: `W A S D` · J2: flechas |
| Capy Run | Toca para saltar; mantén **Agacharse** para esquivar. | `Espacio` / `↑` salta · `↓` se agacha |
| 2048 Clásico | Desliza en la dirección deseada. | Flechas o `W A S D` · `Z` deshace |

## 💻 Ejecutarlo en tu computadora

Necesitas Node.js y npm.

```bash
npm install
npm run dev
```

Abre la dirección local que muestre Vite, normalmente <http://localhost:5173/>.

Para generar una versión de producción:

```bash
npm run build
```

## 🧰 Tecnologías

**React · TypeScript · Vite · Canvas · PeerJS**

Los juegos y la interfaz se ejecutan en el navegador. El modo online conecta directamente los navegadores mediante WebRTC.
